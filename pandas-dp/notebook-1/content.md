# Notebook 1: Pandas basics

In the next few modules, you are learning many common patterns that you will encounter when Processing Data. The focus is on using *Pandas*, the most popular Python library for processing tabular data, but as you will soon see, most principles used in Pandas are common to almost all tools that are designed to deal with data.

The Pandas introduction consist of four notebooks. You'll work through two notebooks in this module and two more in the next.

This first notebook is about the absolut basics. You will see the two structures everything else is built on: the `DataFrame` (a table) and the `Series` (a single column).
